# Bode AI Ad Lab

A premium, mobile-first, multi-page website for Bode AI Ad Lab.

## Pages
- `index.html`: Home
- `work.html`: Portfolio and concept previews
- `services.html`: Creative services
- `about.html`: Studio introduction
- `contact.html`: Contact details
- `assets/styles.css`: Shared responsive design system
- `assets/site.js`: Accessible mobile navigation and shared behavior

## Deploy
This is a static site. Deploy the repository to Vercel using the default static settings. No API keys or environment variables are required. Confirm deployment and test the published domain after pushing changes.

## Portfolio notes
Portfolio tiles are explicitly labelled concept previews, not claims of completed client projects. Replace them with real approved work as it becomes available. For video, use optimized MP4/WebM files or an established video host for larger files.

## Mobile design
The layout includes a compact mobile menu, responsive cards, scalable typography, touch-friendly actions, visible keyboard focus states and reduced-motion support.
