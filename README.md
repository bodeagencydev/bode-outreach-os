# Boot AI Art Lab

A responsive, static portfolio and services website for Boot AI Art Lab.

## Sections
- Home and studio introduction
- AI creative services
- Concept portfolio previews
- Creative process
- About the studio
- Instagram and email contact links

## Deploy
This is a static website. Deploy the repository to Vercel with the default project settings. No build command or environment variables are required.

## Before launch
- Replace concept preview cards with real work when available.
- Confirm the preferred contact email and social profiles.
- Add a custom domain when ready.
- The email contact is currently a placeholder: hello@bootaiartlab.com.
